# מילון מונחים

מילון קצר למונחי הליבה של ZIGZAG · LOOKBACK. סימולציה וחינוך בלבד. כל מונח = משמעות אחת.

| מונח | הגדרה קצרה |
|------|------------|
| **ZIGZAG** | מתודולוגיית המסחר הלימודית: תכנון ניהול פוזיציה לאורך תנועות אפשריות — לא רדיפה אחרי ניבוי בודד. |
| **LOOKBACK** | פילוסופיית המבט לאחור: סקירת החלטות ולמידה מהתנהגות — אינה אות כניסה ואינה הבטחת תשואה. |
| **השבחת העסקה** | שיפור מדוד של פוזיציה באמצעות חיזוקים אופציונליים תחת כללים ותקרה — לא הגדלה רגשית חסרת גבול. |
| **תקציב העסקה** | המסגרת הכספית שקבעתם לפוזיציה לימודית (מרג׳ין עד $250 עם Reject). עדיף על «הקצאה» כשמדברים על מסגרת העסקה. |
| **גודל העסקה** | הכמות (וה־notional הנגזר) שמנהלים בפוזיציה. עדיף על שימוש מעורפל ב«חשיפה» כשמתכוונים לגודל מנוהל. |
| **מרג׳ין** | הון שולי שהוקצה במפורש לפוזיציה. אינו זהה ל־notional או להון הפנוי בחשבון. |
| **Notional** | גודל רעיוני של הפוזיציה (גדל עם מינוף). אינו «כסף בכיס». |
| **הון פנוי / ביטחונות פנויים** | מה שנותר בסימולציה לכיסוי ולפוזיציות נוספות אחרי תקציבי העסקה הפעילים. |
| **מחיר ייחוס P₀** | מחיר הפתיחה/הייחוס המקורי לסולם ה־adverse של הפוזיציה. |
| **סולם 10%** | רמות adverse של 10% מ־P₀. הפעלה ב־**Touch**. חישוב סף מדויק (Decimal). |
| **Touch** | מגע במחיר הסף — תנאי להפעלת רמת סולם / שיקול חיזוק. |
| **Reject** | דחיית חיזוק שחורג מתקרת המרג׳ין $250 לפוזיציה. |
| **×1 → ×10** | מעבר שלב מינוף לימודי לפי **תקרת תקציב** (לא טריגר של הפסד PnL בלבד); הכמות הקיימת נשמרת. |
| **×10 (חיזוק)** | בשלב ×10: חיזוק כאשר הפסד נטו ≥ המרג׳ין הרלוונטי שהוקצה; תקרת מרג׳ין מצטברת $250. |
| **מינוף מקסימלי** | רק מנתוני מכשיר Bybit **מאומתים**; אם לא ידוע — unresolved, בלי המצאה. |
| **מימוש 75%** | סגירת 75% מהכמות הפתוחה (ידני, ניתן לחזרה על היתרה: כל פעם 75% ממה שנותר). |
| **מחיר כניסה ממוצע** | ממוצע משוקלל כמות של מחירי הביצוע בשכבות. |
| **PnL ממומש** | רווח/הפסד אחרי סגירה, במודל כולל עלויות לימודיות רלוונטיות. |
| **PnL לא ממומש** | הערכה פתוחה לפי מחיר סימון — אינה משיכה מובטחת. |
| **פירוק (Liquidation)** | סגירה כפויה במודל בורסה כשהביטחונות אינם מספיקים. צבע רמזור לימודי אינו מבטל פירוק. |
| **Cross / One-Way** | אופן המרג׳ין והכיוון במודל הייחוס הלימודי (Bybit Linear USDT Perpetual). |
| **עמלות / סליפג׳ / מימון** | במודל בסיסי: 2bps הלוך־חזור · 1bp לצד · funding 0. |
| **Long-only** | במודל המאושר: כיוון ארוך בלבד; Short כבוי. |
| **Win Rate / Profit Factor / Drawdown / Expectancy / Recovery Factor** | מדדי קריאה לימודיים; דוגמאות מספריות חייבות תווית HYPOTHETICAL אלא אם צוין אחרת. |

**שפה מועדפת:** תקציב העסקה · גודל העסקה · השבחת העסקה · LOOKBACK · ZIGZAG.
